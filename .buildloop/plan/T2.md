## Departures
- The card is hosted by `NSHostingController` (not `NSHostingView`) because the
  view's `fittingSize` is zero with sizing options off; `sizeThatFits(in:)` works.
- Card placement uses `pillFrame(revealed: true)`, not the live panel frame,
  because `select()` from the concealed state is still animating the slide.
- Added a DEBUG-only `DistributedNotificationCenter` hook so the state machine
  can be driven for screenshots: synthetic mouse events are blocked without
  Accessibility rights on this machine. Documented in CLAUDE.md.
- `ClaudeUsageDecoder` now drops unknown window keys whose utilization is 0;
  the live endpoint shipped an internal codename window at 0 percent.
- `cardWidth` 280 -> 300 so the servers metrics column stops truncating.
- `HUDController` subclasses `NSObject` for `NSMenuItem` targets.
- After the demo video (codenotch-demo.mp4): cards open on hover, not click;
  the outside-click monitors are gone; `peek` is 5 pt, not 14.
- Zac asked for real brand marks and a swept, less boxy shape: added
  `App/Assets.xcassets` with Claude and GitHub Copilot from Simple Icons and
  OpenAI from SVG Logos (both CC0, see THIRD_PARTY.md), template-rendered in
  the rings and card titles; pill ears are cubic quarter circles (26 pt) with
  28 pt left corners; both surfaces carry an 8 percent white hairline.
