## 5d Security review (security-auditor subagent, 10 findings)
### Fixed
- MEDIUM pid reuse inside the SIGTERM grace window: `terminate(pid:startedAt:)` re-checks the start time on every tick and before SIGKILL; a mismatch counts as gone.
- MEDIUM portless hostname used raw in a clickable URL: only bare `*.localhost` hostnames are trusted (`PortlessRoutes.isTrustedHost`); others fall back to `localhost:<port>` and are not auto-web. URL built with URLComponents.
- LOW argv[0] resolved through PATH in a login shell: `ProcArgs` keeps the kernel's executable path and the relaunch runs that, quoted.
- LOW `Shell.find` appended $PATH: fixed allowlist of directories only.
- LOW probe followed redirects: `NoRedirects` delegate.
- LOW log filename from package.json: `safeLogName` whitelist, 64 chars, no leading dots.
- LOW watchdog only SIGTERM: SIGKILL two seconds later and pipe read ends closed.
- LOW pid 0 or negative reachable in theory: dropped in `LsofParser`, refused in `terminate`.
- LOW version mismatch: project.yml is 0.3.1.

### Open, not fixable here
- HIGH ad-hoc signature, no notarization: `scripts/release.sh` signs with Developer ID and the hardened runtime, notarizes and staples, and refuses to tag otherwise. The keychain holds only an "Apple Development" identity and no notarytool profile, so every build from this machine is still ad-hoc. The cask never uses `--no-quarantine`.

### Accepted
- Log files are opened by shell `>>`, not O_NOFOLLOW. The name is whitelisted and the directory is the user's own Library/Logs.
- Debug builds keep the DistributedNotificationCenter hook, which any local process can drive; Release excludes it.
