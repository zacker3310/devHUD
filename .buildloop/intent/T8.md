# Intent: fold in what Codenotch does better

**id:** T8   **originator:** Zac ("he open sourced today, go run and combine all the best features", 2026-09-05)   **date:** 2026-09-05
**status:** accepted

## Problem
vinzdg/codenotch went public today. It has ideas devHUD lacks: ring colour by
how close a limit is, a live "is Claude working or waiting on me" indicator
with the sessions listed, human reset copy, dimmed stale readings, click to
pin a card, hide for an hour, slower polling when nothing is running, and a
Cursor provider.

## Constraints
- The repository publishes no license. Nothing is copied: features are
  re-implemented from the README and design spec and from the data formats
  the tools themselves write (Claude Code session files, Cursor's state DB).
- devHUD keeps its own shape (pill, cards, servers) and its own tests.

## Not doing
Top and bottom edges, Sparkle updates, Antigravity (not installed here),
Perplexity (web session scraping), a settings window.
