# Intent: Docker containers

**id:** T10   **originator:** Zac ("should this thing be able to monitor docker too? Yes")   **date:** 2026-09-05
**status:** accepted

## Desired outcome
Running containers appear in the Dev Servers card with name, compose project,
image, published ports, health, CPU and memory. A web port opens in the
browser on click; stop asks once in the row; restart is one click. The badge
counts containers alongside listeners. Docker absent or stopped shows one
quiet line, never an error dialog.

## Constraints
- Read through the docker CLI from fixed paths; no socket protocol of our own.
- Stats are slow (about 1.7 s per call): poll them less often than the list.
