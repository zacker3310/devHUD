# Intent: act on a dev server

**id:** T4   **originator:** Zac ("go, start with kill/restart and open in editor")   **date:** 2026-09-04
**status:** accepted

## Problem
The servers card is read-only. The one action a dev HUD is for, stopping or
bouncing a server and jumping to its code, still means finding the terminal.

## Desired outcome
Hovering a row shows four actions: open in editor, open terminal at the cwd,
restart, kill. Kill asks once in the row. Restart brings the same command back
in the same directory. Failures show in the row, not in a dialog.

## Constraints
- These are the only destructive actions in the app (TASKS.md). Kill needs a
  confirm step; restart is kill plus relaunch and inherits it.
- Relaunch must go through the login shell so nvm, pnpm and friends resolve.
- No new permissions: same-user processes only.

## Not doing
- Restarting a wrapper we did not see (a `pnpm dev` whose node child is the
  listener restarts as the node child). Environment beyond the login shell.
