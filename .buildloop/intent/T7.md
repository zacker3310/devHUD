# Intent: ship 0.3.1 through Homebrew

**id:** T7   **originator:** Zac (2026-09-05)   **date:** 2026-09-05
**status:** accepted

## Problem
devHUD runs on one Mac from a script. Zac wants a tagged release other
developers can install with Homebrew, including on managed MacBooks without
admin rights, with a security review first.

## Desired outcome
`brew install --cask zacker3310/tap/devhud` (with `--appdir=~/Applications`
for non-admins) installs a signed, notarized 0.3.1 from a GitHub release.
A release script and a CI workflow produce that artifact from a tag.
SECURITY.md states what the app touches. The known injection path is closed.

## Constraints
- Distribution needs a Developer ID Application certificate and notarization
  credentials Zac must create; the pipeline must refuse to tag without them.
- The deploy gate blocks publishing without RELEASE_AUTHORIZED; that stays.
- Homebrew downloads anonymously: the release, or the whole repo, must be public.

## Not doing
Sparkle or any in-app updater. A .pkg or DMG. App Store.
