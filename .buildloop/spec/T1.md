# Spec: devHUD v1

**id:** T1   **intent:** .buildloop/intent/T1.md
**policies applied:** build-loop, root CLAUDE.md style (no em-dashes, explicit code), TASKS.md visual spec
**status:** accepted

## Summary
A SwiftUI macOS app (XcodeGen, SPM dep DynamicNotchKit 1.1.0) with three
independent data stores feeding one DynamicNotch. Compact state shows three
mini usage rings and a server-count badge; expanded state shows an AI Usage card
and a Dev Servers card. Every provider caches last-good data, backs off on
failure, and renders `--` when it has nothing.

## Requirements
R1. Menu bar item, `LSUIElement = true`, no Dock icon. Menu: Show/Hide HUD, Refresh, Quit.
R2. `UsageProvider` protocol with `ClaudeUsageProvider`, `CodexUsageProvider`, `CopilotUsageProvider`.
R3. Claude: token from `~/.claude/.credentials.json` (`claudeAiOauth.accessToken`), GET
    `https://api.anthropic.com/api/oauth/usage` with `anthropic-beta: oauth-2025-04-20`.
    Decode any top-level window object carrying `utilization` and `resets_at`;
    `five_hour` is primary, the rest secondary.
R4. Codex: newest `~/.codex/sessions/**/*.jsonl` lines with `payload.rate_limits`;
    `primary` and `secondary` carry `used_percent`, `window_minutes`, `resets_at`
    (epoch seconds) or `resets_in_seconds`. No network. Snapshot carries the line timestamp.
R5. Copilot: `gh auth token` via Process, GET `https://api.github.com/copilot_internal/user`.
    Primary window is `premium_interactions` when `has_quota`, else `chat`.
    Percent used = 100 - `percent_remaining`. Reset from `quota_reset_date` (YYYY-MM-DD).
R6. Ports: `lsof -iTCP -sTCP:LISTEN -P -n -F pcn` parsed into (pid, command, port),
    deduped by pid+port, system daemons filtered by a denylist.
R7. Enrichment via libproc: cwd (`PROC_PIDVNODEPATHINFO`), start time
    (`PROC_PIDTBSDINFO`), RSS and CPU time (`proc_pid_rusage`). CPU percent is the
    delta between consecutive samples. Project name is the cwd basename, or the
    `name` in `cwd/package.json` when present.
R8. Portless: read `~/.portless/routes.json`; join on port, show `hostname` in place
    of the raw port and tag the row.
R9. Poll cadences: usage 120s, ports 4s, portless 12s. Each store polls on its own
    task; a failing provider never blocks another.
R10. Visual tokens from TASKS.md: black background, `#2C2D2C` track, `#F04A15`
    Claude, `#2BE99A` Codex, `#EFFD31` Copilot, `#E8E8E8` icons, white text,
    55 percent white secondary. Activity-ring stroke, round caps, 12 o'clock start.

## Design
```
DevHUDApp (SwiftUI App, MenuBarExtra)
└── HUDController (@MainActor, owns DynamicNotch + stores + poll tasks)
    ├── AIUsageStore  (@Observable; [ProviderID: ProviderState])
    │     └── providers: Claude, Codex, Copilot (each `UsageProvider`)
    ├── PortsStore    (@Observable; [DevServer]; lsof + libproc)
    └── PortlessStore (@Observable; [Int: PortlessRoute])
Views: CompactLeading (3 rings) · CompactTrailing (badge) · ExpandedHUD (2 cards)
```
Parsers are pure functions over `String` / `Data` so they are unit-testable with
no I/O: `LsofParser.parse`, `CodexSessionParser.snapshot(fromLines:)`,
`ClaudeUsageDecoder.decode`, `CopilotUsageDecoder.decode`, `PortlessRoutes.decode`.

Backoff: `ProviderState` keeps `lastGood`, `failures`, `nextAttempt`. Delay =
min(base * 2^failures, 30 min).

## Acceptance criteria
AC1. `xcodegen generate && xcodebuild -scheme devHUD build` exits 0 | CHECK:build
AC2. `xcodebuild test` passes every parser test | CHECK:tests
AC3. Launched app has no Dock icon and shows a menu bar item | manual, screenshot
AC4. Floating panel renders both cards; Copilot ring shows a real percentage | manual, screenshot
AC5. Dev Servers card lists a known listener started for the test (`python3 -m http.server`) | manual, screenshot
AC6. With `~/.portless` absent the app runs without error | CHECK:run-log

## Ordering surface
concurrency: three poll loops writing to `@Observable` stores read by SwiftUI.
Every mutation happens on the main actor; provider fetches are `nonisolated`
async and return values. No shared mutable state outside the actor. Triage: no
model check; the surface is a single-writer pattern.

## Policy conflicts
None. Kill action deferred by intent, not by policy.

## Rejected alternatives
- Codex via `~/.codex/auth.json` + network: needs an undocumented endpoint and a
  credential read. Local JSONL gives the same numbers with no secret handling.
- `portless list` shell-out: the binary is absent here and the JSON file is the
  source of truth the CLI itself reads.
- libproc port enumeration: TASKS.md defers it to v1.x.
