# Spec: Docker containers

**id:** T10   **intent:** .buildloop/intent/T10.md
**status:** accepted

R1. `DockerContainer { id, name, image, state, status, health, project, ports: [PortMapping] }`.
    `DockerPS.parse(lines:)` reads `docker ps --format '{{json .}}'` rows; ports from the Ports
    string ("0.0.0.0:54322->5432/tcp, [::]:54322->5432/tcp") deduped by host port; project from
    the `com.docker.compose.project` label; `shortImage` drops registry and tag.
R2. `DockerStats.parse(lines:)` reads `docker stats --no-stream --format '{{json .}}'` into
    id -> (cpu percent, memory text).
R3. `DockerStore` finds the binary in /usr/local/bin, /opt/homebrew/bin, ~/.orbstack/bin,
    ~/.docker/bin, Docker.app; polls ps every 5 s and stats every 15 s, detached; a non-zero exit
    means Docker is not running: `isAvailable = false`, containers empty, no error surfaced.
R4. Host ports are classified once with `ServerProbe` (web, api, tcp) and cached by port.
R5. Rows: name, project chip, image, port chips, health or state, cpu and memory. Hover: restart,
    stop (confirm in the row). Click opens the first web port. The badge and the card count
    listeners plus containers.
