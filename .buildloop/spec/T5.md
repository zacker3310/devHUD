# Spec: launch at login

**id:** T5   **intent:** .buildloop/intent/T5.md
**status:** accepted

## Requirements
R1. `LoginItem` wraps `SMAppService.mainApp`: `isEnabled`, `statusText`, `set(_:)`.
R2. `HUDState.launchAtLogin` mirrors the status; refreshed on start and whenever a menu opens.
R3. Gear menu and MenuBarExtra both carry a checked "Launch at Login" item.
R4. `scripts/install.sh` builds Release, copies to `/Applications/devHUD.app`, launches it.
R5. DEBUG hook: `login:on`, `login:off`, `login:status` log the status and bundle path.

## Acceptance criteria
AC1. build + tests green | CHECK:build
AC2. after install, `login:on` from the /Applications copy logs "enabled" | CHECK:live-login
AC3. `login:off` logs "not registered" | CHECK:live-logoff
