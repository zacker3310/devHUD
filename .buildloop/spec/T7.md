# Spec: release pipeline and security hardening

**id:** T7   **intent:** .buildloop/intent/T7.md
**status:** accepted

## Requirements
R1. `ProcessInspector.arguments(pid:)` reads argv via KERN_PROCARGS2; `ProcArgs.parse` is pure.
    `ServerCommand.relaunchScript(argv: [String], ...)` quotes every token.
R2. Kill and restart re-check the process start time against the row before signalling.
R3. `scripts/release.sh <version>`: stamps versions, runs tests, builds Release with Developer ID +
    hardened runtime when `DEVHUD_SIGN_IDENTITY` is set (ad-hoc with a warning otherwise), zips with
    ditto, notarizes and staples when the `devhud-notary` keychain profile exists, writes sha256,
    updates the cask, tags only when notarized and the tree is clean. Exit 2 otherwise.
R4. `packaging/homebrew/Casks/devhud.rb`: GitHub release zip, sonoma+, login item uninstall, zap.
    Passes `brew style` and offline `brew audit` in a local tap.
R5. `.github/workflows/release.yml`: on `v*` tag, imports the Developer ID p12 and notary key from
    secrets, runs the script, publishes the GitHub release with RELEASE_AUTHORIZED set by the tag
    pusher, uploads the cask as an artifact for the tap.
R6. `SECURITY.md` lists reads, sends, executes, writes, sandbox stance, reporting.
R7. Security review by an independent reviewer; HIGH and MEDIUM findings fixed or explicitly accepted.

## Acceptance criteria
AC1. tests green incl. hostile argv and ProcArgs | CHECK:tests
AC2. live restart via exact argv | CHECK:live-restart
AC3. `scripts/release.sh 0.3.1` on this machine builds, packages, exits 2 (ad-hoc) | CHECK:dry-run
AC4. cask passes brew style and offline audit | CHECK:cask
AC5. security review findings triaged in verify | CHECK:security
